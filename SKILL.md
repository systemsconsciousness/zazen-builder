# Zazen Builder: Skills-Based Universal Site Builder (v3.2.0)
**From Zazen Labs, LLC • Canonical Skill Specification**

Build self-contained, AI-first websites and web applications that run universally anywhere—in browser canvas previews, static web buckets, or edge CDNs. **Zazen Builder is 100% client-side and requires zero build pipelines, zero package managers, and no server runtime.**

---

## 1. Universal Workflow & Harness Compatibility

Zazen Builder works natively across **both Web and Local AI harnesses**:

```
[User Invokes Skill with Brief]
              │
              ▼
  [Optional Scoping: 0-3 Questions Max]
              │
              ▼
  ┌────────────────────────────────────────────────────────┐
  │         Agent Generates Self-Contained index.html       │
  │     (HTML5, Tailwind CDN, Lucide, Studio Typography,   │

  └───────────────────────────┬────────────────────────────┘

          ┌───────────────────┴───────────────────┐
          ▼                                       ▼
  IN WEB HARNESSES                        IN LOCAL HARNESSES
  (Gemini Web, Claude, ChatGPT)           (Cursor, Claude Desktop, CLI)
  • Renders in Canvas / Artifact          • Saves index.html & zazen.config.json
  • 100% in-browser editing               • Runs in localhost or file://
  • Client-side JSZip download            • 1-Click Git commit & push
```

### Protocol A: In Web Agent Harnesses (Gemini Web, Claude.ai, ChatGPT)
- **Zero Runtime Requirement:** The agent does not execute terminal commands or run servers.
- **Delivery:** The agent outputs the complete, self-contained `index.html` directly in the canvas/artifact window.
- **Editing:** The user edits visually right inside their browser canvas (inline typing, dragging sections, testing palettes).
- **Export:** The user clicks **[Pure ZIP]** to instantly download the clean production bundle from the browser.

### Protocol B: In Local IDE / CLI Harnesses (Cursor, Claude Desktop, CLI)
- The agent writes `index.html` and `zazen.config.json` to the workspace.
- The user can double-click `index.html` or open `http://localhost:3000` via the included lightweight static helper.
- The user clicks **[Commit & Push]** to sync directly with GitHub or **[Deploy]** to prepare MCP handoffs.

## 2. Interactive In-Browser Visual Builder

Every site generated by Zazen Builder includes an authoring overlay that runs 100% in client-side JavaScript:

1. **Authoring vs. Production Mode (Environment Variable Protection):**
   - **Strict Security Mandate:** The editor is NEVER exposed to the public through URL query parameters or public flags.
   - **Default Live Production Mode:** On any live cloud host (e.g. `*.vercel.app`, custom domain), all builder bars, component drawers, and editing handles are automatically and completely scrubbed from the DOM, rendering as a **100% pristine, static agency website**.
   - **Optional Cloud Authoring via Environment Variable:** A site owner can enable remote authoring on their cloud host by setting the environment variable `ZAZEN_EDIT=true` (or `zazen-edit=true`) in their provider's dashboard (e.g. Vercel / Netlify environment variables), which injects `<meta name="zazen-edit" content="true">` or `window.ZAZEN_EDIT = true`.
   - **The Cloud-to-Local Git Bridge:** When `ZAZEN_EDIT=true` is set on the cloud host, the builder overlay can securely link back to the site owner's local bridge daemon (`http://localhost:3000`). This allows the owner to visually edit on their private cloud deployment and click **[Commit & Push]** to trigger automated Git commits and cloud redeployments directly from their local machine.

2. **Native Inline Text Editing:**
   - All headings, subheadings, metrics, and narrative text carry `.zazen-editable`.
   - Clicking allows instant editing in the browser.
   - Edits reactively sync to the embedded JSON data store (`__ZAZEN_DATA`).

3. **Drag-and-Drop Reordering:**
   - Major sections and modular blocks feature native HTML5 drag-and-drop (`draggable="true"`).
   - Dragging reorders content visually and updates the underlying JSON data array.

4. **Studio Component Library Drawer (`+ Add Block`):**
   - Click to append pre-styled design primitives:
     - Metric / Stat Cards
     - Experience Entries
     - Editorial Pullquotes
     - Distinction & Honor Badges
     - Featured Project Cards
     - Civic & Advisory Roles

5. **Live Palette & Typography Swapping:**
   - Instantly switch between 4 studio palettes (Editorial Sand, Warm Linen, Architect White, Obsidian Darkroom).
   - Instantly switch typography pairings (Newsreader + Inter, Cormorant + Plus Jakarta).

## 3. Decentralized State Architecture

All site content, metrics, navigation, and theme tokens are stored in a clean, decentralized JSON structure inside `<script id="__ZAZEN_DATA" type="application/json">[...]</script>` and mirrored in `zazen.config.json`.

**The DOM is a pure reactive projection of this state.** Whenever the state updates (via inline edits, git pull, or component insertion), the entire page updates seamlessly.

```json
{
  "meta": {
    "title": "Site Title",
    "author": "Creator Name",
    "palette": "editorial",
    "font": "newsreader",
    "location": "New York, NY",
    "status": "Available"
  },
  "summary": "High-impact narrative statement...",
  "metrics": [],
  "competencies": [],
  "experience": [],
  "honors": [],
  "civic": [],
  "education": [],
  "customBlocks": []
}
```

## 4. Universal 3-Tier Deployment Matrix

```
┌────────────────────────────────────────────────────────────────────────┐
│                        ZAZEN BUILDER TOP BAR                           │
│  [Add Block]   [Pure ZIP]        [Commit & Push]        [Deploy Host]  │
└─────────────────────┬───────────────────┬──────────────────────┬───────┘
                      │                   │                      │
                      ▼                   ▼                      ▼
               TIER 1: UNIVERSAL    TIER 2: GIT REPO       TIER 3: HOST MCP
               (Web & Local)        (Local Clones)         (Local & Web)
               • 1-Click JSZip      • Stage, commit & push • Exports ./dist
               • Pure production    • Triggers Vercel/host • Agent: "deploy"
               • Drag & drop        • Zero CLI commands
```

### Tier 1: Pure Production ZIP (Universal / Web & Local)
- Uses client-side JSZip to scrub the DOM (stripping `#zazen-builder-bar`, modals, `contenteditable`, and builder scripts).
- Downloads `<project>-production.zip` containing 100% clean, production-ready `index.html` + `zazen.config.json`.
- Drag and drop directly into Vercel Drop, Netlify Drop, Cloudflare Pages, S3, or FTP.

### Tier 2: 1-Click Git Commit & Push (Cloud Auto-Deploy)
- When developing in a local repository clone, clicking **[Commit & Push]** stages all visual edits, creates a git commit, and pushes to GitHub.
- Pushing to GitHub automatically triggers connected frontend hosts (Vercel, Netlify, Cloudflare Pages) to rebuild and deploy live.

### Tier 3: Host Agent & MCP Deployment Handshake
- Exports clean production files into `./dist/` and writes `.zazen/deploy-intent.json`.
- In your AI agent harness, the user simply types `"deploy"`, and the agent triggers the corresponding MCP tool (`vercel`, `launch`, `netlify`, `wrangler`).

## 6. Local Bridge Helper (Built on the Fly in Local Harnesses)

In local IDE or CLI harnesses, the agent automatically creates `bridge.js` on the fly from the specification below and launches it via `node bridge.js` to power local authoring, auto-saving, and 1-click git synchronization:

```javascript
// Zero-dependency local bridge helper (bridge.js)
const http = require('http');
const fs = require('fs');
const path = require('path');
const { execSync } = require('child_process');

const PORT = process.env.PORT || 3000;
const ROOT_DIR = process.cwd();
const DIST_DIR = path.join(ROOT_DIR, 'dist');
const ZAZEN_DIR = path.join(ROOT_DIR, '.zazen');

const MIME_TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.svg': 'image/svg+xml',
  '.png': 'image/png',
  '.jpg': 'image/jpeg',
  '.ico': 'image/x-icon'
};

function setCorsHeaders(res) {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'GET, POST, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');
}

function getGitInfo() {
  try {
    const branch = execSync('git rev-parse --abbrev-ref HEAD', { encoding: 'utf8', stdio: ['pipe', 'pipe', 'ignore'] }).trim();
    const status = execSync('git status --porcelain', { encoding: 'utf8', stdio: ['pipe', 'pipe', 'ignore'] }).trim();
    return { isGit: true, branch, clean: status.length === 0 };
  } catch (_) {
    return { isGit: false, branch: null, clean: true };
  }
}

const server = http.createServer((req, res) => {
  setCorsHeaders(res);
  if (req.method === 'OPTIONS') { res.writeHead(204); return res.end(); }

  const parsedUrl = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
  const pathname = parsedUrl.pathname;

  // Health Check
  if (req.method === 'GET' && pathname === '/api/health') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    return res.end(JSON.stringify({ status: 'ok', bridge: 'zazen-local', version: '3.2.0', git: getGitInfo() }));
  }

  // Auto-Save
  if (req.method === 'POST' && pathname === '/api/save') {
    let body = '';
    req.on('data', chunk => { body += chunk; });
    return req.on('end', () => {
      try {
        const { data, html } = JSON.parse(body);
        if (data) fs.writeFileSync(path.join(ROOT_DIR, 'zazen.config.json'), JSON.stringify(data, null, 2), 'utf8');
        if (html) {
          fs.writeFileSync(path.join(ROOT_DIR, 'index.html'), html, 'utf8');
        } else if (data) {
          const indexPath = path.join(ROOT_DIR, 'index.html');
          if (fs.existsSync(indexPath)) {
            let current = fs.readFileSync(indexPath, 'utf8');
            const regex = /<script id="__ZAZEN_DATA" type="application\/json">([\s\S]*?)<\/script>/;
            if (regex.test(current)) {
              const rep = `<script id="__ZAZEN_DATA" type="application/json">\n${JSON.stringify(data, null, 2)}\n  </script>`;
              current = current.replace(regex, () => rep);
              fs.writeFileSync(indexPath, current, 'utf8');
            }
          }
        }
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'success' }));
      } catch (e) {
        res.writeHead(500, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'error', error: e.message }));
      }
    });
  }

  // 1-Click Git Commit & Push
  if (req.method === 'POST' && pathname === '/api/git') {
    let body = '';
    req.on('data', chunk => { body += chunk; });
    return req.on('end', () => {
      try {
        const { message = 'feat: update site via Zazen Builder', push = true } = JSON.parse(body || '{}');
        execSync('git add -A', { cwd: ROOT_DIR, encoding: 'utf8' });
        const status = execSync('git status --porcelain', { cwd: ROOT_DIR, encoding: 'utf8' }).trim();
        let commitOut = 'Working tree clean, nothing to commit.';
        if (status.length > 0) {
          commitOut = execSync(`git commit -m "${message.replace(/"/g, '\\"')}"`, { cwd: ROOT_DIR, encoding: 'utf8' }).trim();
        }
        let pushOut = null;
        if (push) {
          try { pushOut = execSync('git push', { cwd: ROOT_DIR, encoding: 'utf8' }).trim(); } catch (pe) { pushOut = `Push note: ${pe.message}`; }
        }
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'success', commit: commitOut, push: pushOut, branch: getGitInfo().branch }));
      } catch (e) {
        res.writeHead(500, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'error', error: e.message }));
      }
    });
  }

  // Tier 3 Clean Export & Deploy Intent
  if (req.method === 'POST' && pathname === '/api/deploy') {
    let body = '';
    req.on('data', chunk => { body += chunk; });
    return req.on('end', () => {
      try {
        const { provider = 'universal', project = 'zazen-site', files = {} } = JSON.parse(body);
        if (!fs.existsSync(DIST_DIR)) fs.mkdirSync(DIST_DIR, { recursive: true });
        if (!fs.existsSync(ZAZEN_DIR)) fs.mkdirSync(ZAZEN_DIR, { recursive: true });
        for (const [name, content] of Object.entries(files)) {
          fs.writeFileSync(path.join(DIST_DIR, name), content, 'utf8');
        }
        fs.writeFileSync(path.join(ZAZEN_DIR, 'deploy-intent.json'), JSON.stringify({ provider, project, timestamp: new Date().toISOString(), outputDir: 'dist' }, null, 2));
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'success', outputDir: DIST_DIR }));
      } catch (e) {
        res.writeHead(500, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ status: 'error', error: e.message }));
      }
    });
  }

  // Static File Serving
  let filePath = path.join(ROOT_DIR, pathname === '/' ? 'index.html' : pathname);
  if (!fs.existsSync(filePath)) { res.writeHead(404); return res.end('Not Found'); }
  if (fs.statSync(filePath).isDirectory()) filePath = path.join(filePath, 'index.html');
  const ext = path.extname(filePath).toLowerCase();
  res.writeHead(200, { 'Content-Type': MIME_TYPES[ext] || 'application/octet-stream' });
  fs.createReadStream(filePath).pipe(res);
});

server.listen(PORT);
```
